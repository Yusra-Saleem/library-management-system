# Library Circulation System

> Book cataloging, member loans, and inventory circulation tracking system.

## Overview

A structured library administration software system built to maintain bibliographic catalogs, register student/faculty memberships, manage book borrowing/returns, and calculate overdue fines.

## Key Features

- Full CRUD operations for book cataloging by ISBN, author, and genre
- Member registration and borrowing limit enforcement
- Automated loan duration tracking and overdue fine calculation
- Clean menu-driven console and data persistence layer

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/library-management-system.git
cd library-management-system
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
